# Berkontribusi

Terima kasih telah membantu Ruang Semester. Untuk melaporkan bug, jelaskan langkah reproduksi, hasil yang diharapkan, hasil aktual, browser dan sistem operasi. Gunakan data contoh; jangan kirim jadwal atau data mahasiswa asli.

Gunakan Node.js 20 atau lebih baru untuk menjalankan `npm test`. Untuk perubahan antarmuka, buka `index.html` melalui localhost dan uji keyboard serta alur terkait. Sertakan pengujian untuk perubahan perilaku penting dan perbarui README bila ada batas atau format cadangan yang berubah.

Jika menemukan masalah keamanan yang melibatkan data pengguna, jangan sertakan data pribadi pada laporan publik.
